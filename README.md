### 🔐 [LockIt](https://github.com/Ariyan-Ebrahimi/Lockit)

**A modern desktop application for secure local file encryption and decryption.**
Built with **Python & PySide6**, distributed as a standalone Windows application — no Python required on the user's machine.

| Feature | Description |
| :-- | :-- |
| 🔒 **File Encryption** | Protect files through a simple, guided desktop interface |
| 🔓 **File Decryption** | Restore encrypted files securely and reliably |
| 🔑 **Password Protection** | Password-based file protection with salted key derivation |
| 📊 **Password Strength Meter** | Real-time feedback while the user sets a passphrase |
| 🛡️ **100% Local Processing** | Encryption and decryption never leave the device |
| 🖥️ **Modern UI** | Clean, modern interface built with PySide6 |
| 🌙 **Dark Theme** | Polished dark-mode interface by default |
| ⚡ **Background Processing** | File operations run off the UI thread — no freezing |
| 📦 **Windows Installer** | Installs like any standard Windows application |
| 🚀 **Standalone Build** | End users need no Python runtime at all |
